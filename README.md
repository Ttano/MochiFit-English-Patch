This is an ***unofficial translation tool and is not affiliated with or endorsed by Nine Gates / Omochi Nobiru.***
**Please download and install the Blender Add-on before applying this patch.** *It won't do anything otherwise as it's only looking for the specific string values in the MochiFitter blender Add-on .py scripts*

This tool changes the string text in the UI of the Blender Add-on for Mochi Fitter (and was unfortunately made with AI because I haven't ever used python.)

# HOW TO USE #
1. [REQUIRED] Download the Mochi Fitter Blender Add-on:
  https://drive.google.com/file/d/1T7GLfY_vkXNU2XxaRt__Fos8s7tmADYX/view?usp=sharing
2. [REQUIRED] Any version of blender:
  http://blender.org/
3. Install the add-on using Edit -> Preferences -> Install from disk, and select the .ZIP folder from the drive link
4. Close Blender
5. Target your blender add-on. It's usually in C:\Users\UserName\AppData\Roaming\Blender Foundation\Blender\5.0\scripts\addons\MochiFitter
6. Click the green button to translate, and the red button to revert the add-on UI back to the original Japanese
7. Close and then re-open Blender to refresh the add-on any time you run the .exe file

# HOW IT WORKS #
It works by finding the names and replacing them with an english equivalent, while also creating a backup .bak of the original unmodified scripts so you can revert it easily again with the same tool.
This code only impacts string values. If you use it on a file that isn't mochifitter it won't do anything.

これは、Mochi Fitter用BlenderアドオンのUI内の文字列を変更する外部ツールです。
残念ながら、私はPythonを使ったことがないので、AIを使って作成しました。
Blenderアドオンをターゲットにしてください。通常、以下のパスにあります：C:\Users\UserName\AppData\Roaming\Blender Foundation\Blender\5.0\scripts\addons\MochiFitter
